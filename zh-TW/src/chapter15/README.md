# 快取、渲染與部署

這一章要回答三個問題：

1. **網頁是什麼時候產生的？** 是建置的時候一次做好，還是每次有人來才現做？
2. **產生過的東西可以記起來嗎？** 記多久？資料改了之後怎麼讓記憶過期？
3. **做好的網站怎麼放到網路上？**

前兩個問題是同一件事的兩面：**要在「快」和「新」之間取得平衡**。每次都現做，內容永遠最新，但是慢；做一次就記起來，很快，但是可能過期。Next.js 16 的 Cache Components 讓你用幾個簡單的指令，決定每一塊內容要怎麼取捨。

接著我們補上兩個前面沒有講的檔案類型：**Route Handler**（自己寫 API）和 **`proxy.ts`**（在請求抵達頁面之前先處理它），再學環境變數，最後是 `next build`、`next start` 和部署。

這一章延續第 14 章的留言板。你要先有一個能運作的 `/guestbook`，以及 `app/lib/guestbook.ts` 裡的 `getMessages`、`addMessage` 和 `removeMessage`。

這一章的結果，很多都要靠 `npm run build` 加 `npm run start` 才看得到，開發模式（`npm run dev`）看不出差別。如果某一集的範例要你執行這兩個指令，請照做。
