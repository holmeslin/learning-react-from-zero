# React Router

到目前為止，你做的網頁只有一頁。但真正的網站有很多頁：首頁、商品列表、單一商品、聯絡我們。網址一變，畫面就換成對應的內容。

用 React 做這件事的時候，瀏覽器其實只載入了一次網頁，之後換頁都是 JavaScript 在背後把畫面換掉，而不是重新向伺服器要一份新的 HTML。這種網頁叫**單頁應用程式**（single-page application，簡稱 SPA）。讓網址和畫面對得起來的工具，就叫**路由**（router）。

React 本身沒有路由功能，所以要另外裝一個套件。這一章用的是 **React Router**，它是目前最多人用的路由函式庫。React Router 有三種使用方式，這本書教最單純的那一種，叫 **Declarative mode**（宣告式模式）：你用 JSX 把「哪個網址對應哪個元件」寫出來，就完成了。

這一章會在你的 `hello-react` 專案裡，一步一步做出一個小型商品網站：

1. 設定第一個路由
2. 用連結換頁
3. 共用版面與巢狀路由
4. 網址上的參數，例如 `/products/3`
5. 網址上的查詢參數，例如 `?category=mouse`
6. 用程式碼換頁
7. 找不到頁面時顯示 404

第二部會教 Next.js，它的路由是用「檔案放在哪個資料夾」來決定的，寫法和這一章不一樣。但「網址對應畫面」、「網址有參數」、「共用版面」這些觀念是相通的，先在這裡學會，之後會輕鬆很多。
