# Ref 與 Effect

到目前為止，你寫的元件都只做一件事：根據 props 和 state，算出畫面該長什麼樣子。這個「算出畫面」的過程叫做渲染，而且應該是純粹的：同樣的輸入，永遠得到同樣的畫面。

但真實的網頁不只有畫面。你還會需要：

- 在使用者點按鈕後，讓輸入框自動取得游標。
- 在畫面更新之後，把瀏覽器分頁的標題改掉。
- 開啟計時器、連上聊天室、從伺服器抓資料。

這些事情都發生在 React 管不到的「外面」，不能直接塞在渲染過程裡。React 為此準備了兩個工具：

- **Ref**：讓你保存一個「不影響畫面」的值，或是拿到真正的 DOM 元素。
- **Effect**：讓你在畫面更新之後，執行跟外部系統同步的程式碼。

這一章會依序介紹這兩個工具，最後學會把重複的邏輯抽成自己的 Hook。

這一章的範例都放在你的 `hello-react` 專案裡，把 `src/App.jsx` 整個換成範例的程式碼，存檔後瀏覽器就會自動更新。需要看 `console.log` 輸出的地方，請打開瀏覽器的開發者工具（按 F12，或 Mac 按 ⌘⌥I），切到「Console」分頁。
