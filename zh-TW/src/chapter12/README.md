# Next.js 入門

第一部你用 Vite 做出來的網站，有一個特點：瀏覽器拿到的 HTML 幾乎是空的，所有畫面都是瀏覽器下載 JavaScript 之後才畫出來的。這種做法叫**單頁應用程式**（single-page application，簡稱 SPA）。

第二部要換一種做法：讓伺服器先把畫面算好，再傳給瀏覽器。要做到這件事，你不用自己從頭寫伺服器，因為有現成的框架可以用，這本書選的是 **Next.js**。

這一章先把 Next.js 的基本功學起來：怎麼建立專案、資料夾怎麼變成網址、怎麼在頁面之間跳轉、資料還沒到的時候畫面要怎麼處理、網址不存在的時候要怎麼辦。這些東西你在 React Router 那一章學過類似的，Next.js 只是用不同的方式做到。

接下來整個第二部，我們會一起做一個「小書店」網站，一章一章往上加功能。

## 開始前你需要

- 第一部讀完，尤其是第 10 章的 TypeScript，因為第二部的程式碼全部用 TypeScript 寫。
- Node.js 24，也就是你第 1 章裝的那個版本。Next.js 要求的最低版本是 20.9，所以只要你的版本不比它舊就可以。
- VS Code 和終端機。
