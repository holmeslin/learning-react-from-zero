# 互動與 state

上一章做出來的畫面，無論你怎麼點、怎麼打字，它都不會變。真正的網頁會回應你：按讚數字加一、輸入文字立刻出現搜尋結果、勾選待辦事項就畫上刪除線。

這一章要學的，就是讓畫面「活」起來，核心只有一個東西：**state**。學完這一章，你會從「描述畫面長什麼樣子」，進步到「描述畫面如何隨著資料改變」，而且最後會做出一個完整的待辦清單。

這一章是整本書最重要的一章。React 之所以好用，幾乎都來自 state 的設計。請放慢速度，每一集都動手做。

## 準備環境

這一章繼續使用 `hello-react` 專案，開發伺服器（`npm run dev`）保持開著。這一章的範例比較少用到樣式，所以大部分的檔案只有 JavaScript 和 JSX，沒有 CSS。

你需要先熟悉第 4 章的內容，特別是元件、props、條件渲染和列表。這一章的每一個觀念，都建立在它們之上。

## 這一章的主題

1. 事件處理：讓畫面對操作有反應。
2. 為什麼一般的變數不行，需要 state。
3. 用 `useState` 記住資料，並且理解 state 的行為：快照、更新函式。
4. 物件和陣列的 state 要怎麼正確地更新。
5. 受控輸入與表單。
6. 當兩個元件需要共用資料時，state 該放在哪裡。
7. 綜合練習：待辦清單。
