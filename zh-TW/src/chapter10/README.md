# TypeScript

前面的章節，你一直在寫 JavaScript。它很自由：變數裡想放數字就放數字，想放字串就放字串，程式碼不會事先攔你。但這份自由有代價：很多錯誤要等程式跑起來、使用者點到那個按鈕，才會發現。

**TypeScript** 是在 JavaScript 上多加了一層**型別**（type）：你可以事先說明「這個變數是數字」、「這個元件要收這些 props」，然後由編輯器在你寫程式的當下，就把對不上的地方標成紅線。它不是另一種語言，所有 JavaScript 的寫法都還能用，只是多了「事先說明」這件事。

這一章會從「為什麼需要」開始，然後學最常用的部分：基本型別、物件、聯集型別、元件的 props、state 與事件、泛型，最後把你的 `hello-react` 專案改成 TypeScript。

這一章不是型別理論課，不會教你所有的功能。目標很實際：讓你能讀懂、能寫出 React 專案裡常見的 TypeScript，因為第二部的 Next.js 專案預設就是 TypeScript，而且你在網路上看到的 React 範例，現在大多也是。

學這一章要有第 4～9 章的基礎。整章都在你的 `hello-react` 專案裡進行，第 1 集會先準備好練習的環境。
