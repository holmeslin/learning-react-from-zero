# Server Components

上一章你寫的每個頁面，其實都是 **Server Component**，只是我們一直沒有明講。這一章要把這件事講清楚。

Server Component 是 React 的一項功能：有些元件只在伺服器上執行，它們的程式碼不會被送到瀏覽器。好處是：可以直接讀資料、可以放心使用金鑰、瀏覽器下載的 JavaScript 也比較少。

但是伺服器上的元件沒辦法回應使用者的操作。按鈕要點、輸入框要打字，這些需要在瀏覽器裡執行。所以 React 還有另一種元件：**Client Component**，也就是你在第一部寫的那種元件。

這一章要學的，就是怎麼把這兩種元件組合在同一個網站裡：誰該是 Server、誰該是 Client、中間的邊界怎麼畫、資料怎麼傳過去。學會這些，你就掌握了 Next.js 最核心的觀念。
