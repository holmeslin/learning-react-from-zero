# 函式與現代 JavaScript

第 1 章你學會了存資料、做判斷、走訪陣列。這一章要學的是怎麼把程式碼**包成可以重複使用的零件**，以及一批 React 幾乎每一行都會用到的現代 JavaScript 寫法。

這一章的重點有三個：

- **函式**：把一段程式碼取個名字，需要的時候再呼叫它。React 的元件本質上就是函式。
- **處理陣列的方法**：`map`、`filter` 這些東西，是之後把資料變成畫面的主力。
- **解構、展開、`async` / `await`**：看起來是小語法，但 React 的程式碼裡到處都是，不熟的話會一直卡住。

這一章的程式一樣用 Node.js 執行，用法和第 1 章相同：存成 `.js` 檔，然後 `node 檔名`。只有第 13 集（`import` / `export`）會用到 `.mjs` 檔，到時候會說明。

這一章比第 1 章難一些，因為觀念之間是一層疊一層的。遇到卡關的地方，退一集重讀，再自己動手改改範例，通常就通了。
