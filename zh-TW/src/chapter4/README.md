# 第一個 React 程式

從這一章開始，我們終於要寫 React 了。

這一章要學的是 React 的骨架：怎麼建立專案、元件是什麼、JSX 怎麼寫、怎麼把資料傳給元件、怎麼把一串資料畫成清單。學完之後，你可以做出一個「靜態」的頁面，也就是畫面長什麼樣子都由資料決定，但還不會對你的操作有反應。讓畫面動起來是下一章 state 的工作。

## 準備環境

這一章開始，練習都在一個用 Vite 建立的專案裡進行，專案名稱叫 `hello-react`。**從這一章到第 11 章，你都會在同一個專案裡練習**，所以下一集建好之後，請好好保留它。

你需要：

- 已經安裝好 Node.js 24 和 VS Code（第 1 章第 2 集）。
- 懂基本的 JavaScript（第 1、2 章）和 HTML、CSS（第 3 章）。特別是陣列的 `map` 和 `filter`、物件解構、展開語法，這一章會一直用到。

## 這一章的範例怎麼讀

每個範例的前面，都會用像 `src/App.jsx` 這樣的寫法告訴你要把程式碼放進哪個檔案。檔案路徑是從專案資料夾 `hello-react` 開始算的。範例通常是整個檔案的內容，直接整個換掉原本的內容就可以了。
